# CANNA — מדריך למשתמש

כתובת המערכת: **https://app.cannaforyou.net**
לכל מרפאה יש גם כתובת משלה, למשל `https://<שם-המרפאה>.cannaforyou.net`, עם הלוגו והצבעים שלה.

המערכת בעברית ומותאמת למחשב ולנייד. יש בה ארבעה תפקידים: **מנהל מרפאה**, **רופא**, **איש צוות** ו**מטופל**. כל משתמש רואה רק את המסכים ואת הנתונים של התפקיד ושל המרפאה שלו.

---

## 1. הקמת מרפאה חדשה

1. נכנסים ל-`https://app.cannaforyou.net/onboarding` (או "הקמת מרפאה" בדף הבית).
2. **פרטי המרפאה:** שם, אימייל וטלפון ליצירת קשר, ושם לכתובת המרפאה (תת-דומיין).
3. **פרטי המנהל:** שם, אימייל וסיסמה. מי שמקים את המרפאה הופך למנהל שלה.
4. **תוכנית:** בחירת מסלול המנוי.
5. **מיתוג:** לוגו, צבע ראשי וצבע משני, עם תצוגה מקדימה.
6. **רופא ראשון (לא חובה):** שם ואימייל. הרופא מקבל הזמנה באימייל.

בסיום המרפאה פעילה, הכתובת שלה מוגדרת אוטומטית, והמנהל מקבל אימייל ברוכים הבאים.

## 2. מנהל המרפאה

| מסך | מה עושים בו |
|---|---|
| **לוח בקרה** | הכנסות, תורים, תורים ממתינים לאישור, רופאים, מטופלים, שימוש ב-AI וגרפים |
| **ניהול תורים** | כל התורים של המרפאה, חיפוש וסינון לפי סטטוס (היום, ממתינים, פעילים, הושלמו, בוטלו) |
| **משתמשים** | רופאים, צוות ומטופלים; "הזמן משתמש" שולח הזמנה באימייל; "הזמנות ממתינות" מציג הזמנות שעוד לא מומשו, עם אפשרות להעתיק את הקישור |
| **לידים** | פניות של מטופלים פוטנציאליים |
| **שאלונים** | בניית שאלוני קליטה למטופלים |
| **תבניות הודעות** | נוסחי ההודעות שנשלחים למטופלים באימייל וב-WhatsApp (אישור תור, תזכורות, ביטול, סיכום ביקור ועוד), עם משתנים כמו שם המטופל ומועד התור |
| **אינטגרציות** | WhatsApp (Green API), אימייל, וידאו, תשלומים (Tranzila), חשבוניות ודומיין; כולל שליחת אימייל בדיקה והודעת WhatsApp בדיקה |
| **דוחות** | הכנסות, תורים ושימוש ב-AI לפי תקופה |
| **יומן פעילות** | מי עשה מה ומתי, עם סינון לפי פעולה, סוג ותאריך |
| **הגדרות** | קישור הרשמה למטופלים (להעתקה או לשליחה ב-WhatsApp), דומיין המרפאה, פרטי המרפאה, לוגו וצבעים, שעות, מחירים, מדיניות ביטול ותזכורות |
| **חיוב ומנוי** | תוכנית המנוי של המרפאה |

**הזמנת רופא:** משתמשים ← "הזמן משתמש" ← שם, אימייל ותפקיד. הרופא מקבל אימייל עם קישור אישי שתקף 7 ימים. אם פג תוקף, שולחים הזמנה חדשה.

**צירוף מטופלים:** מעתיקים את קישור ההרשמה מעמוד ההגדרות ושולחים למטופל. מי שנרשם דרכו משויך אוטומטית למרפאה.

## 3. רופא

**הצטרפות:** פותחים את קישור ההזמנה מהאימייל, משלימים שם וסיסמה, ומאשרים את כתובת האימייל בקישור שנשלח. מי שכבר יש לו חשבון מתחבר עם הסיסמה שלו, חוזר לקישור ההזמנה, ולוחץ "השלם הצטרפות".

| מסך | מה עושים בו |
|---|---|
| **לוח בקרה** | תורים להיום, ממתינים לאישור, ביקורים החודש, דירוג, והייעוץ הבא |
| **יומן** | תצוגה שבועית ויומית של התורים |
| **שעות פעילות וחופשות** | ימים ושעות קבלה, וימי חופשה |
| **תורים** | אישור בקשות, קביעת מועד, פתיחת שיחת וידאו, תיעוד SOAP (תלונה, ממצאים, הערכה, תוכנית), הערכת AI של הפנייה, הפקת מסמך רפואי, וסיום ייעוץ |
| **מטופלים** | רשימת המטופלים והיסטוריית הביקורים |
| **פרופיל** | התמחויות, שפות, מחיר ייעוץ ותיאור |

**סיום ייעוץ:** בסיום השיחה (או בלחיצה על "סיים ייעוץ") התור מסומן כהושלם, **סיכום AI נוצר אוטומטית** ונשמר בתיק, והמטופל מקבל הודעה. הרופא יכול לעבור על הסיכום ולערוך אותו.

## 4. מטופל

1. **הרשמה:** דרך הקישור שהמרפאה שלחה, או בכתובת המרפאה ← "הרשמה". אחר כך מאשרים את האימייל.
2. **קביעת תור:** תור חדש ← התמחות ← רופא ← מועד פנוי ← תיאור הפנייה ← העלאת מסמכים (לא חובה) ← אישור.
3. **התורים שלי:** סטטוס כל תור, כניסה לשיחת הווידאו, ביטול תור.
4. **המסמכים שלי:** העלאה וצפייה במסמכים רפואיים. המסמכים פרטיים ונפתחים בקישור זמני ומאובטח בלבד.
5. **אחרי הביקור:** סיכום הביקור מופיע בלוח הבקרה, ונשלחת הודעה באימייל.

## 5. שיחת וידאו

בזמן התור נכנסים לשיחה מתוך "התורים". יש חדר המתנה ובדיקת מצלמה ומיקרופון לפני הכניסה. צריך לאשר לדפדפן גישה למצלמה ולמיקרופון.

## 6. העוזר החכם (AI)

כפתור **"עוזר חכם"** פתוח בכל מסך, לכל התפקידים. כותבים אליו בעברית רגילה.

- **מה הוא יודע:** רק את הנתונים שהמשתמש מורשה לראות. מטופל רואה את התורים שלו; רופא את המטופלים והתורים שלו; מנהל את נתוני המרפאה.
- **דוגמאות:** "מתי התור הבא שלי?", "מה הייעוץ הבא שלי?", "תן לי סיכום של החודש", "האם ה-WhatsApp מחובר?", "תעביר אותי ליומן".
- **פעולות:** כשמבקשים פעולה (למשל לבטל תור או להזמין רופא), העוזר מציג **כרטיס אישור**. שום דבר לא מתבצע עד שלוחצים "אישור". כל פעולה נרשמת ביומן הפעילות.
- **גבולות:** העוזר אינו נותן ייעוץ רפואי, ומסרב לבקשות שהמשתמש אינו מורשה להן (למשל גישה לנתוני מרפאה אחרת).

## 7. הודעות אוטומטיות

| אירוע | אימייל | WhatsApp |
|---|---|---|
| קבלת בקשת תור / תור חדש לרופא | ✓ | ✓ * |
| אישור וקביעת מועד | ✓ | ✓ * |
| תזכורת 24 שעות ושעה לפני התור (כולל קישור לשיחה) | ✓ | ✓ * |
| ביטול תור | ✓ | ✓ * |
| סיכום ביקור | ✓ | ✓ * |
| הזמנת משתמש / ברוכים הבאים | ✓ | — |

\* WhatsApp נשלח רק אחרי שהמרפאה חיברה חשבון Green API משלה (סעיף 8), ורק למשתמשים ששמרו מספר טלפון.

סטטוס המסירה של כל אימייל (נמסר / חזר / חסום) מתעדכן אוטומטית כל 30 דקות.

## 8. חיבור WhatsApp (Green API) — פעם אחת לכל מרפאה

1. פותחים חשבון ב-green-api.com ויוצרים Instance.
2. בטלפון של המרפאה: WhatsApp ← הגדרות ← מכשירים מקושרים ← סורקים את קוד ה-QR מ-Green API.
3. מעתיקים את ה-Instance ID ואת ה-API Token.
4. במערכת: אינטגרציות ← WhatsApp ← מדביקים ושומרים.
5. שולחים הודעת בדיקה למספר שלכם.

אפשר לשאול את העוזר החכם "האם ה-WhatsApp מחובר?". הוא בודק מול Green API ומסביר מה חסר.

## 9. אבטחה ופרטיות

- כל מרפאה רואה רק את הנתונים שלה. ההפרדה נאכפת בבסיס הנתונים עצמו.
- כל משתמש רואה רק מה שהתפקיד שלו מתיר.
- מסמכים רפואיים נשמרים באחסון פרטי ונפתחים בקישור זמני בלבד.
- כל פעולה רגישה נרשמת ביומן הפעילות.
- תפקיד מורשה (רופא, צוות, מנהל) ניתן רק דרך הזמנה תקפה מהמנהל.

## 10. תמיכה

בכל תקלה או שאלה פונים לצוות הפיתוח. כדאי לציין את המסך, את השעה ואת מה שהופיע.
